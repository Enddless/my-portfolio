## Общая информация
Персональное портфолио с проектами, фильтрацией и слайдером. Разработано на React + TypeScript с архитектурой Feature-Driven Development (FSD).

## Структура проекта
```
src/
├── app/          # инициализация приложения (провайдеры, стили, store)
├── pages/        # страницы
├── widgets/      # крупные блоки страниц (Header, ProjectsSection)
├── features/     # пользовательские действия (ProjectCard, ProjectFilter)
├── entities/     # бизнес-сущности (Project)
└── shared/       # переиспользуемый код (UI, стили, хуки)
```

## Используемые технологии
- **React 19** + **TypeScript** — библиотека и строгая типизация
- **Redux Toolkit** + **React-Redux** — управление состоянием
- **Swiper** — слайдер проектов
- **SCSS** — стили с переменными и миксинами
- **ESLint** + **Prettier** — линтинг и форматирование
- **Vite** — сборщик

## Команды
- `npm run dev` — запуск dev-сервера
- `npm run build` — сборка (typecheck + vite build)
- `npm run lint` — проверка линтером
- `npm run preview` — предпросмотр сборки
